# Space Box Launchpad

Build a premium, modern, high-end website for "Space Box", a gaming and entertainment venue in La Marsa, Tunisia.

IMPORTANT:

- This is a real business website intended to be shown to the business owner.

- Do NOT invent specific facts such as prices, opening hours, phone numbers, addresses, activities, or social-media accounts unless they are explicitly provided.

- Where information is unknown, use tasteful placeholders that are easy to replace later.

- Do not use lorem ipsum.

- Do not mention that the website was AI-generated.

- The result must feel like a professionally designed commercial website, not a generic template.

========================================

BRAND / VISUAL DIRECTION

========================================

Create a dark futuristic gaming aesthetic.

Primary visual atmosphere:

- Deep black / near-black backgrounds

- Dark charcoal surfaces

- Electric blue accents

- Purple/violet secondary accents

- Subtle neon glow

- High contrast typography

- Premium glassmorphism used sparingly

- Subtle gradients

- Soft shadows and atmospheric lighting

- Modern gaming/entertainment feeling without becoming childish

The website should feel similar to a premium gaming lounge / esports venue / entertainment brand.

Avoid:

- Excessive neon

- Rainbow gradients

- Cartoonish gaming graphics

- Cheap-looking gamer templates

- Excessive glass effects

- Clutter

- Huge amounts of text

- Generic stock-photo aesthetics

Use strong spacing, large typography, clean grids, and intentional composition.

========================================

TYPOGRAPHY

========================================

Use a modern premium display font for major headings and a highly readable modern sans-serif for body text.

Headings should be bold, distinctive and cinematic.

Use typography to establish hierarchy rather than relying on excessive visual effects.

========================================

NAVIGATION

========================================

Create a sticky transparent/dark navigation bar.

Left:

- Space Box logo/name

Navigation:

- Home

- Activities

- Experience

- Gallery

- About

- Contact

Right:

- Prominent CTA button: "Book / Contact Us"

On mobile:

- Replace navigation links with a clean animated hamburger menu.

- Keep the primary CTA easily accessible.

Navigation should become slightly more opaque when scrolling.

========================================

HERO SECTION

========================================

Create a cinematic full-screen hero section.

Background:

- High-quality gaming/entertainment imagery

- Dark overlay so text remains extremely readable

- Subtle blue/purple atmospheric lighting

Hero content should include:

Small eyebrow:

"LA MARSA • TUNISIA"

Main heading:

"LEVEL UP YOUR EXPERIENCE."

Supporting text:

"Gaming, competition and entertainment — all in one place."

Primary CTA:

"Discover Space Box"

Secondary CTA:

"Contact Us"

Add subtle animated visual elements such as:

- glowing gradients

- particles

- light streaks

- very subtle grid patterns

Keep animations smooth and restrained.

Add a small scroll indicator near the bottom.

========================================

ACTIVITIES SECTION

========================================

Create a premium activities section.

Heading:

"MORE THAN JUST GAMING."

Supporting copy should communicate that Space Box is an entertainment destination where people can come to play, compete and spend time with friends.

Create a responsive card grid.

Each activity card should have:

- Large visual/image

- Activity title

- Short description

- Small arrow/icon

- Hover animation

- Subtle neon glow on interaction

IMPORTANT:

Do not invent specific activities if Space Box's actual activity list is unknown.

Instead, create clearly labelled editable activity placeholders such as:

- "Activity 01"

- "Activity 02"

- "Activity 03"

- "Activity 04"

Make the data structure easy to replace with the real Space Box activities later.

========================================

EXPERIENCE SECTION

========================================

Create a visually striking split-layout section.

Left:

- Large atmospheric image

Right:

Heading:

"BUILT FOR THE EXPERIENCE."

Explain the atmosphere in general terms:

- immersive gaming

- friendly competition

- groups of friends

- memorable entertainment

- modern environment

Add a few visual feature points with icons.

Example:

"Immersive Atmosphere"

"Competitive Energy"

"Perfect for Groups"

Do not make unsupported claims about specific equipment or technology.

========================================

WHY SPACE BOX

========================================

Create a premium statistics/features section.

Use 3–4 visual feature blocks instead of fake numerical statistics.

Examples:

"Play"

"Compete"

"Connect"

"Experience"

Each should have a short explanation.

Do NOT invent numbers such as:

"20+ consoles"

"500+ visitors"

"10 gaming rooms"

unless real information is provided.

========================================

GALLERY

========================================

Create a large cinematic gallery section.

Use a sophisticated masonry/grid layout.

Images should show:

- Gaming environments

- People enjoying entertainment

- Controllers / gaming setups

- Neon interiors

- Competitive gaming atmosphere

Use high-quality relevant imagery.

Do not use unrelated generic office images.

Add hover effects:

- subtle zoom

- dark overlay

- image title/category

On mobile, make the gallery easy to swipe/scroll.

========================================

ABOUT SECTION

========================================

Create an "About Space Box" section.

Keep the copy concise and premium.

Position Space Box as:

- a gaming and entertainment destination

- a place to meet friends

- a place to compete

- a place to enjoy immersive entertainment

Do not invent the company's history, founding year, founders, awards, or achievements.

========================================

LOCATION / VISIT SECTION

========================================

Create a strong "Come Visit Us" section.

Include:

- Location placeholder

- Google Maps embed placeholder

- Contact information placeholders

- Opening-hours placeholders

Clearly structure the information so it can easily be replaced with verified details.

Add CTA:

"Plan Your Visit"

========================================

CONTACT SECTION

========================================

Create a premium contact section.

Include:

- Name

- Phone

- Email

- Message

Primary CTA:

"Send Message"

Also include a prominent WhatsApp CTA.

Use:

"Chat on WhatsApp"

Do not invent the WhatsApp number.

Use a clearly identifiable placeholder in the code/data structure so the number can be replaced easily.

========================================

SOCIAL MEDIA

========================================

Add social icons for:

- Instagram

- Facebook

- TikTok

Do not link them to generic homepages such as instagram.com or facebook.com.

Use placeholder URLs that are clearly labelled for later replacement, or disable the links until the real accounts are known.

========================================

FOOTER

========================================

Create a minimal premium footer.

Include:

- Space Box branding

- Navigation links

- Social links

- Contact

- Location

- Copyright

Example:

"© 2026 Space Box. All rights reserved."

========================================

RESPONSIVE DESIGN

========================================

The website MUST be excellent on:

- Desktop

- Laptop

- Tablet

- Mobile

Pay particular attention to:

- 360px wide phones

- 390px wide phones

- 430px wide phones

No horizontal scrolling.

Images must scale correctly.

Text must never overflow.

Buttons must remain easy to tap.

========================================

ANIMATIONS

========================================

Use modern, subtle animations.

Include:

- Smooth scrolling

- Fade/slide reveals

- Hover transitions

- Image zoom on hover

- Navbar transition on scroll

- Subtle hero animation

- Mobile menu animation

Do NOT make every element animate.

Animations should feel premium and fast.

Respect prefers-reduced-motion.

========================================

TECHNICAL REQUIREMENTS

========================================

Use React + TypeScript and the existing Lovable project architecture.

Keep components modular and maintainable.

Create reusable components for:

- Navbar

- Hero

- ActivityCard

- Gallery

- FeatureCard

- Contact

- Footer

Keep business information in a centralized configuration/data structure where practical so it can easily be replaced later.

Use semantic HTML.

Add:

- proper page title

- meta description

- Open Graph metadata

- descriptive alt text

- accessible buttons and links

- keyboard-friendly navigation

Optimize images and avoid unnecessarily huge assets.

Do not add unnecessary dependencies.

Do not break the existing build.

========================================

IMPORTANT FINAL REQUIREMENT

========================================

Before finishing:

1. Check every section for responsive layout problems.

2. Check mobile navigation.

3. Check all buttons and links.

4. Check that there is no horizontal overflow.

5. Check that text remains readable over images.

6. Check that no fake business information has been presented as fact.

7. Make sure placeholder business information is obvious in the code.

8. Make sure the website feels like a premium real-world gaming venue.

9. Make sure the design is cohesive from hero to footer.

10. Run/build the project and fix any errors.

Do not stop after creating the basic layout.

The final result should look like a website that could realistically be presented to Space Box as a professional commercial website.
